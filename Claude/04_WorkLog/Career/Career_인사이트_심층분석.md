## 1. 현재 포지션 자기 인식

GPT와의 31개 메시지 심층 대화(2025-04-19)에서 확인된 자기 인식:

- **결과 중심 + 전략적 사고**: 데이터 분석을 시각화 목적이 아니라 협상력 확보·비용 절감·전략 제안 도구로 활용
- **프레임워크 기반 실행**: 추상적 개념도 즉시 행동 가능한 구조로 전환
- **CBO를 명확한 장기 목표로 인식**: 이직 탐색 자체가 "CBO 퍼즐 조각 맞추기"
- **현재 포지션의 레어함 인식**: 자율주행 도메인 + OpenX 표준 + 데이터 플랫폼 PM을 동시에 보유한 조합은 국내에 거의 없음

## 3. CBO 경로 타임라인

대화에서 반복적으로 등장한 커리어 설계:

```
현재 → 데이터 분석가 → 플랫폼 PM/PO → 전략가 → 기획자 → CBO
```

**현재 위치 진단 (2026-03 기준)**:
- "데이터 분석가"와 "플랫폼 PM" 사이 — 두 역할을 동시에 수행 중
- Nova 서비스 기획·릴리즈 관리 = PO에 가장 근접
- 부족한 것: 사업 단위 P&L 경험, 팀 리더십 공식 경험

**다음 전환점 조건**:
- Analytics Engineer 포지션 또는 플랫폼 PM 타이틀 확보
- 팀 단위 → 사업부 단위 영향력 확장

## 4. 이력서·포트폴리오 전략

### 확정된 프레임워크

**경력기술서: PAR 구조**
```
Problem → 내가 마주한 문제/과제
Action  → 어떻게 접근·해결했나 (구체적 방법론, 데이터, 툴)
Result  → 정량적(숫자) 또는 정성적 결과
```

**이력서 핵심 구성 (IT 표준)**
1. Header: 이름/연락처/LinkedIn/GitHub/포트폴리오
2. Professional Summary: 3~5줄 커리어 방향성 요약
3. Skills: SQL·Power BI·Python·Jira·도메인 지식
4. Work Experience: PAR 구조로 각 경력 서술
5. Projects: Nova 서비스, OpenLABEL 마이그레이션, WLS

### 강조할 핵심 경험 (포지셔닝 근거)

| 포지션 타겟 | 강조 포인트 |
|------------|-------------|
| Analytics Engineer | dbt Lakehouse 설계, PostgreSQL/BigQuery 경험, ETL 파이프라인 |
| 데이터 전략가 | KPI→OKR 전환, Nova 로드맵 작성, 단가 협상 전략 |
| 플랫폼 PM/PO | Nova 서비스 기획·릴리즈 관리, Jira 티켓 체계 수립, R&R 재정의 |
| 자율주행 도메인 전문가 | ASAM OpenX 전체 연계 아키텍처, SV→OpenLABEL 마이그레이션 |

## 5. 핵심 인사이트 Top 5

**[1] "이직 탐색은 기준 잡기 위한 탐색이었다"**
- 크래프톤·빗썸·펄어비스를 조사했지만 도메인 이탈 리스크가 크다는 판단
- 결과: 현직 내 Nova·Databricks 전환 경로로 집중

**[2] 도메인 전문성이 최대 차별화 포인트**
- GPT가 반복적으로 짚은 것: 자율주행 OpenX 표준 + 데이터 플랫폼 PM 조합은 "레어"
- 이직 시 이 조합을 버리면 범용 PM/분석가로 포지셔닝 하향됨

**[3] 연봉 벤치마크: 크래프톤 전체 평균(1억 831만) 수준이 목표선**
- 현재 연봉과의 갭이 이직 동기였으나 도메인 리스크가 더 크다고 판단

**[4] 이력서보다 포트폴리오가 먼저**
- 88 메시지짜리 이력서 작성법 대화 → 결론: "증거 기반 포트폴리오 없이 이력서만으로는 부족"
- Nova 서비스, OpenLABEL 마이그레이션, WLS가 포트폴리오 핵심 소재

**[5] CBO 경로에서 "지금 여기서 무엇을 증명할 것인가"가 핵심 질문**
- 이직이 아니라 현직에서 사업부 단위 영향력 확장이 더 빠른 경로일 수 있음
- Databricks 기반 Nova Beta Launch가 그 증명의 첫 번째 스텝
