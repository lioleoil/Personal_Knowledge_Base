파일을 저장할 때는 항상 아래 경로를 기본 저장 경로로 사용한다.

**고정 저장 경로:** `C:\Users\psh93\OneDrive\Desktop\Claude`

**Why:** 사용자가 명시적으로 지정한 경로. 메모리 시스템 경로(`.claude/projects/...`)가 아닌 OneDrive Desktop의 Claude 폴더를 기준으로 삼아야 한다.

**How to apply:** 문서, 분석 결과, 마크다운 파일 등 사용자에게 전달하는 모든 파일을 저장할 때 이 경로를 기본으로 사용한다. 별도 경로 지정이 없으면 이 경로에 저장한다.
