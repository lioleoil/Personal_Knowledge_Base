# Plan: PM Skill Interactive Launcher 재설계

## Context
기존 pm_skill.py는 27개 스킬명을 직접 입력해야 해서 사용이 어려웠음.
목표: 명령어 하나로 실행 → 터미널에서 toolkit 카테고리 개요 표시 → 구조화된 입력 수집 → Claude가 후보 스킬 2-3개 제시 → 사용자가 번호 선택 → 자동 실행.

---

## 최종 플로우

```
python pm_skill.py
       ↓
[터미널] 카테고리 개요 (한 화면, 스킬명 없이 키워드만)
       ↓
[터미널] 3단계 input() 수집
  [1/3] 목적
  [2/3] 컨텍스트
  [3/3] 원하는 산출물 형태
       ↓
[터미널] [PM_SKILL_REQUEST] 블록 출력
       ↓
[Claude] 분석 → 후보 스킬 2~3개 번호와 함께 제시
       ↓
[사용자] 번호 선택 → Claude가 해당 스킬 자동 실행
```

---

## 터미널 출력 설계

### 1단계: Toolkit 개요
```
╔══════════════════════════════════════════════╗
║            PM Skill Toolkit                  ║
╚══════════════════════════════════════════════╝

  📋 실행          PRD · 유저스토리 · 스프린트 · 회고 · 회의록 · OKR
  🔍 제품 발견     아이디어 발산 · 가정 식별 · OST · 인터뷰 분석
  🎯 제품 전략     전략캔버스 · 가치제안 · SWOT · 린캔버스
  📊 시장 조사     경쟁사 분석 · 시장규모(TAM/SAM) · 고객여정맵
  📈 데이터 분석   A/B 테스트 · 코호트 분석 · SQL 생성
  🚀 GTM           GTM전략 · ICP · 배틀카드 · 성장루프
  📣 마케팅·성장   North Star 메트릭 · 포지셔닝 · 마케팅 아이디어
  🛠  툴킷          문법교정 · 이력서 리뷰 · NDA · 개인정보처리방침

──────────────────────────────────────────────
원하는 작업을 설명하면 최적 스킬을 찾아드립니다.
```

### 2단계: 3단계 입력 수집
```
[1/3] 목적 — 이 작업으로 달성하려는 것은?
> ___

[2/3] 컨텍스트 — 제품명 / 상황 / 타겟 유저 / 관련 정보
> ___

[3/3] 원하는 산출물 형태 — 문서 / 표 / 요약 / 한국어 등
> ___
```

### 3단계: 출력 블록
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[PM_SKILL_REQUEST]
목적: {purpose}
컨텍스트: {context}
산출물: {deliverable}
[/PM_SKILL_REQUEST]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Claude가 위 요청을 분석합니다...
```

### Claude 응답 형태 (후보 제시)
```
→ [분석] 관련 스킬 후보:
  1. sprint-plan       — 스프린트 계획 수립
  2. retro             — 스프린트 회고
  3. brainstorm-okrs   — OKR 설정

번호를 선택하세요: _
```
→ 사용자가 번호 입력 → Claude가 해당 스킬 즉시 실행

## 파일 변경 내용

### pm_skill.py — 전면 재작성
**제거**: `show_list()`, `show_skill()`, TEMPLATE, LIST_HEADER, 커맨드라인 인자 처리
**유지**: SKILLS dict (Claude 내부 매칭용)
**추가**:
- `CATEGORY_OVERVIEW` dict — 카테고리별 키워드 문자열
- `show_toolkit()` — 카테고리 개요 출력
- `collect_input()` — 3단계 input() 수집, dict 반환
- `output_request(data)` — `[PM_SKILL_REQUEST]` 블록 출력
- `main()` — 세 함수 순서대로 호출

### user_custom_instructions.md — 트리거 규칙 추가
도구 출력에 `[PM_SKILL_REQUEST]` 블록이 포함되면:
1. 목적·컨텍스트·산출물을 분석
2. SKILLS dict 기준 후보 2~3개를 번호와 함께 제시
3. 사용자가 번호 선택 → 해당 스킬 즉시 실행

---

## 검증 방법
1. `python pm_skill.py` 실행 → 카테고리 개요 한 화면 출력 확인
2. 3단계 입력 후 `[PM_SKILL_REQUEST]` 블록 출력 확인
3. Claude가 후보 2~3개 번호 목록으로 제시하는지 확인
4. 번호 선택 → 스킬 자동 실행 확인
