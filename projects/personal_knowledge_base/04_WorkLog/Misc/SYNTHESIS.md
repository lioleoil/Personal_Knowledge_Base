## 핵심 지식

1. **Chrome 브라우저 확장 프로그램 연결이 Claude Code의 웹 접근 전제조건이다** — `https://example.com` 열기 등 브라우저 제어 작업은 Claude 확장 프로그램이 설치되고, claude.ai와 동일 계정으로 로그인되어야 동작한다. 미연결 시 작업 자체가 불가능하다.

2. **로컬 커맨드 실행 메시지는 Claude가 응답하면 안 된다** — `<local-command-caveat>` 태그로 감싸진 메시지는 사용자가 로컬 명령 실행 중 자동 생성된 것이며, Claude는 이에 응답하지 않아야 한다는 명시적 규칙이 존재한다.

3. **Claude Code는 외부 세션 URL을 통해 작업 연속성을 유지한다** — `https://claude.ai/code/session_...` 형식의 URL로 이전 세션 내용을 참조하고, 모델 설계 반영 여부 확인 및 후속 작업을 신규 브랜치에서 이어가는 워크플로우가 사용된다.

4. **날짜/시간 확인은 단독 세션으로 반복 실행된다** — "현재 날짜와 시간을 알려줘. 한 줄로만 답해." 요청이 동일 파일(`3a56ac53`)에서 여러 번 등장하며, 이는 스크립트 또는 자동화 루틴의 헬스체크 패턴으로 보인다.

5. **동일 파일 ID에 여러 대화 스냅샷이 중복 기록된다** — `897293b0` 파일과 `3a56ac53` 파일이 각각 10회 이상 반복 등장하는 것은 로그 추출 방식의 문제(중복 슬라이싱 또는 페이지네이션 오류)일 가능성이 높다.

## 반복 등장 패턴

- **`local-command-caveat` 메시지 반복 (약 18회):** 단일 파일(`897293b0`)에서 동일 caveat 메시지가 대량 중복 추출됨 → 로그 파이프라인의 중복 제거 로직 부재
- **브라우저 제어 실패 패턴:** `https://example.com` 접근 시도 → 확장 프로그램 미연결 오류 반복 (3개 파일에서 동일 패턴)
- **날짜 확인 요청 반복:** 동일 세션에서 같은 질문이 여러 스냅샷으로 기록됨
- **신규 브랜치 지시:** Claude Code 세션에서 "신규 브랜치로" 지시가 포함된 패턴 — 작업 단위를 브랜치로 격리하는 습관
