## 핵심 지식

1. **스톡옵션 행사가격은 액면분할 시 자동 조정된다** — 100대1 분할 시 행사가격 1,500원 → 15원으로 비례 조정. 3,500개 행사 시 3억 이익을 내려면 매도가 약 85,729원 필요 (계산식: 목표이익/수량 + 행사가격)

2. **국민건강보험공단 장제비는 2008년부터 폐지됨** — 일반 사망·장례에 대한 지급 없음. 특정 법률·정책 기반 보상 제도(산재 등)에서 예외적으로 지원 가능

3. **퇴직연금제도 3가지 유형 구분** — DB형(기업 운영, 확정 급여), DC형(개인 운영, 확정 기여), IRP(개인형, 이직·퇴직 시 통산). 재직 중 유형 확인은 사내 인사팀 또는 고용노동부 퇴직연금 포털에서 가능

4. **"중요도" 영어 표현은 맥락에 따라 다름** — 일반적 중요성: importance / 우선순위 의미: priority / 심각도(IT·위험 관리): severity / 가중치 의미: weight

5. **"해당 연도"는 반드시 띄어 씀** — "해당"은 관형어로 뒤 명사와 항상 띄어 쓰는 것이 한글 맞춤법 원칙

6. **새벽·여명·황혼·먼동 시간대 구분** — 먼동(동트기 직전 희미한 빛) → 여명(해 뜨기 직전 밝아오는 시간) → 새벽(밤 깊은 시간~해 뜨기 전 전체) → 황혼(해 진 직후 어스름)
