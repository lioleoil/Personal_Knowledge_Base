## 직업 및 역할
- 자율주행 데이터 라벨링/어노테이션 관련 업무 담당 (PO 또는 PM에 가까운 역할)
- 데이터 플랫폼 서비스 기획 및 관리 (Nova 대시보드, WLS 등)
- 벤더사(외주 라벨링 업체) 관리 및 단가 협상 경험

## 주요 전문 도메인

### 1. 자율주행 어노테이션 (핵심 업무)
- ASAM OpenLABEL, OpenSCENARIO, OpenDRIVE, OpenODD 표준 작업
- SV(자체 포맷) → OpenLABEL 마이그레이션 프로젝트 수행
- Gen1/Gen2 OD (Object Detection), 3DP, LDRBD, RMD 라벨링 성능 측정
- 2D/3D Bounding Box, Cuboid, Lane 데이터 처리
- 어노테이션 Policy 문서 작성 및 관리 (Jira 티켓 기반)
- 퍼셉션 윈도우 기반 어노테이션, 클래스별 규칙 정의

### 2. 데이터 플랫폼 / 인프라
- **Nova**: 사내 대시보드 서비스 기획 및 릴리즈 관리
- **WLS (Workload Labeling System)**: 워크로드 측정 시스템
- 데이터 스택: MySQL, PostgreSQL, MongoDB, BigQuery, Databricks
- ETL/파이프라인: Airflow, dbt (토이프로젝트 포함)
- BI 툴: Power BI (Python 스크립트 연동), Google Apps Script
- 데이터 레이크하우스, OLAP/OLTP 설계 경험

### 3. 스크립트 개발 (Python 중심)
- JSON/XML 파싱 및 데이터 처리 스크립트 다수 작성
- 파일 복사/이름 변경 자동화, 폴더 구조화 스크립트
- 객체 카운팅, 통계 계산, 데이터프레임 처리
- 병렬 처리, 진행바(tqdm), 인코딩 처리(UTF-8/CP949) 작업 경험

### 4. 업무 문서 / 번역
- 한국어 ↔ 영어 비즈니스 번역 빈번 (기술 용어 + 비즈니스 표현)
- 도로 객체 명칭(Bollard, Barrier, Wheel stopper 등) 영어 표현 정리
- KPI 설정, OKR 전환, 성과 평가 보고서 작성
- Jira 티켓 작성, 비즈니스 메일, 협업 평가 문서
