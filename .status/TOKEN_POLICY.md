# Claude Pro 토큰 사용량 정책

> 최종 업데이트: 2026-03-15

---

## 1. Claude Pro 플랜 제한 구조

Claude Pro는 **2단계 제한**으로 운영된다.

| 제한 단위 | 리셋 주기 | 기준 |
|-----------|-----------|------|
| 5시간 롤링 윈도우 | 5시간마다 자동 리셋 | 핵심 일상 제한 |
| 주간(Weekly) 한도 | 매주 목요일 23시 리셋 | 2025-08-28 도입, 남용 방지용 |

---

## 2. 5시간 롤링 윈도우

### 동작 방식
- 현재 시각 기준으로 **과거 5시간 내** 사용량을 누적 집계
- 5시간 단위로 슬라이딩 리셋 (고정 시각이 아닌 롤링)
- 기준점: `2026-03-14 14:00` 에서 5시간 단위로 계산

### 용량 기준 (짧은 메시지 기준)
- 5시간당 약 **45개 메시지**
- 하루 환산 약 **216개 메시지**

### 실제 소모량 결정 요인
메시지 수가 아닌 **토큰 소비량** 기준으로 산정된다.

| 요인 | 영향 |
|------|------|
| 대화 길이 | Claude는 매 응답마다 전체 히스토리를 재처리 → 50턴 대화는 5턴 대화보다 **8~10배** 소모 |
| 파일 첨부 | 대용량 파일 업로드 시 소모량 급증 |
| 모델 선택 | Opus는 Sonnet 대비 **3~5배** 소모 |

### 현재 설정값
```json
"window_limit": 72000  // 토큰 (관측 기반 추정값)
```

---

## 3. 주간(Weekly) 한도

### 도입 배경
- 2025-08-28 Pro / Max 플랜 동시 적용
- 극단적 사용 패턴 및 남용 방지 목적
- Claude UI 설정 > 사용량에서 프로그레스 바로 확인 가능

### 한도 수준
- 일반 사용자는 **거의 도달하지 않는** 높은 한도로 설정
- 주간 한도에 지속적으로 부딪힌다면 **상위 5% 헤비유저** 수준

### 현재 설정값
```json
"weekly_limit": 500000  // 토큰 (추정값 — Claude가 절대값을 공개하지 않음)
"week_start": "YYYY-MM-DD"  // 해당 주 목요일
```

> **참고**: 2026-03-15 기준 주간 한도의 **30%** 소진 확인 (Claude UI 기준).
> 절대값이 노출되지 않으므로 역산 불가. `weekly_limit` 값은 수동 보정 필요.

## 4. 로컬 추적 시스템

### 파일 구조
```
.status/
├── token_usage.json    # 상태 데이터 (5시간 윈도우 + 주간 누적)
├── show_tokens.py      # 터미널 바 표시 (Stop 훅 자동 실행)
└── token_popup.py      # GUI 팝업 (우하단, 6초 자동 닫힘)
```

### token_usage.json 스키마
```json
{
  "date": "YYYY-MM-DD HH:MM",     // 현재 5시간 윈도우 시작 시각
  "used": 0,                       // 윈도우 내 누적 토큰
  "window_limit": 72000,           // 5시간 윈도우 한도
  "plan": "Pro",
  "week_start": "YYYY-MM-DD",     // 이번 주 목요일
  "weekly_used": 0,                // 주간 누적 토큰 (월요일부터)
  "weekly_limit": 500000,          // 주간 한도 (추정값, 수동 보정 가능)
  "sessions": [...],               // 세션별 기록
  "transcripts": {...}             // 파일별 토큰 집계
}
```

### 리셋 규칙
| 이벤트 | 리셋 대상 |
|--------|-----------|
| 새 5시간 윈도우 시작 | `used`, `sessions`, `transcripts` |
| 새 주(목요일) 시작 | `weekly_used` |
| 동일 윈도우 내 | 아무것도 리셋 안 함 |

## 5. 경고 임계값

### 5시간 윈도우
| 사용률 | 경고 |
|--------|------|
| 75% 이상 | 노란색 경고, 잔여 토큰 표시 |
| 90% 이상 | 빨간색 경고, 속도 제한 임박 알림 |
| 90% 이상 | 팝업 자동 닫힘 비활성화 (직접 닫아야 함) |

### 주간 한도
| 사용률 | 경고 |
|--------|------|
| 60% 이상 | 노란색 경고 |
| 80% 이상 | 빨간색 경고, "상위 5% 헤비유저 구간" 알림 |

## 6. 절약 팁

1. **새 대화 자주 시작** — 히스토리가 짧을수록 메시지당 토큰 소모 감소
2. **질문 묶기** — 여러 질문을 하나의 메시지로 합치면 메시지 수 절감
3. **파일 재업로드 금지** — 같은 대화 내에서는 Claude가 파일을 기억함
4. **Sonnet 우선 사용** — Opus는 3~5배 소모, 복잡한 작업에만 사용
5. **불필요한 긴 대화 지양** — 컨텍스트가 길어질수록 각 응답 비용이 기하급수적으로 증가

---

## 7. 수동 보정 방법

주간 한도의 실제값을 파악했을 때 직접 수정:

```json
// .status/token_usage.json
{
  "weekly_limit": 실제값으로_수정,
  ...
}
```

Claude UI → 설정 → 사용량에서 프로그레스 바 비율과 현재 `weekly_used` 값으로 역산 가능:
```
weekly_limit ≈ weekly_used / (프로그레스_비율 / 100)
```
