# Misc 지식 합성

> 마지막 갱신: 2026-04-22 07:55 | 기반 항목 수: 30

---

## 핵심 지식

1. **스킬 등록 확인 방법**: canvas-design, mcp-builder, theme-factory 스킬 등록 시 단순 설정만으로는 정상 등록되지 않을 수 있으며, 등록 상태를 테이블 형식으로 명시적으로 검증해야 한다.

2. **스톡옵션 행사가격 조정 원칙**: 100대 1 액면분할 시 행사가격도 동일 비율로 조정됨 (예: 1,500원 → 15원). 목표 이익 역산 공식: `매도가 = (목표이익 ÷ 수량) + 행사가격` (예: 3억÷3,500개+15원 ≈ 85,728원).

3. **국민건강보험 장제비**: 2008년부터 일반 장제비 지급 제도 폐지. 현재는 특정 법률·정책 기반 예외 케이스에서만 지원 가능하며, 일반적인 사망·장례에는 지급되지 않는다.

4. **시간대 어휘 구분**: 새벽(밤 깊은 시간~해 뜨기 전) / 여명(동이 트는 순간, 빛이 막 시작되는 때) / 먼동(동쪽 하늘이 밝아오는 시각) / 황혼(해 진 직후 노을 지는 시간). 네 단어 모두 다른 시각대를 가리킴.

5. **Claude Code의 local-command-caveat 패턴**: 로컬 명령 실행 시 자동 생성되는 caveat 메시지는 Claude가 응답해서는 안 되는 시스템 메시지이며, 실제 대화 내용이 아님.

6. **이미지 처리 가능 범위**: OCR로 이미지 텍스트 → 데이터프레임 변환 가능. 업스케일링은 2배·4K 등 목표 해상도 지정 시 처리 가능하나, 실제 AI 처리는 이미지 업로드 후 진행.

## 반복 등장 패턴

- **브라우저 자동화 테스트 반복 시도**: `https://example.com` 열기 + 페이지 제목/본문 추출 요청이 2026-04-11에 5회 반복 등장 → Chrome 원격 제어 또는 브라우저 익스텐션 연동 설정을 반복 시도한 흔적
- **local-command-caveat 메시지 누적**: 2026-04-05, 04-12, 04-14에 걸쳐 반복 등장 → Claude Code 로컬 실행 환경에서 자동 생성되는 노이즈성 로그가 지속적으로 쌓이는 구조
- **단발성 정보 조회**: 날짜 계산, 단어 뜻(여명/황혼), 볼라드 정의, 중요도 영어 표현 등 맥락 없이 단순 사실 확인 목적의 1회성 질문이 다수
- **금융/재직 관련 단발 질문 클러스터**: 스톡옵션(행사가격·매도가 계산), 퇴직연금, 장제비 등 재직 중 재무 의사결정 관련 질문이 2025년 10~11월에 집중
