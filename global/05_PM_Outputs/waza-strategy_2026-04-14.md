## 1. 개요

### 1.1 Waza란?
Waza는 tw93이 개발한 macOS용 웹 애플리케이션 래퍼 도구로, 웹사이트를 네이티브 macOS 앱처럼 사용할 수 있게 해주는 경량 솔루션이다.

### 1.2 주요 특징
- **경량화**: Electron 대비 훨씬 가벼운 리소스 사용
- **네이티브 경험**: macOS 네이티브 앱과 유사한 UX 제공
- **간편한 설정**: 최소한의 설정으로 웹앱을 데스크톱 앱으로 변환
- **성능 최적화**: WKWebView 기반으로 빠른 성능

## 2. 도입 전략

### 2.1 설치 요구사항
- macOS 11.0 이상
- 개발 환경: Xcode 및 Swift/SwiftUI
- 기술 스택: Swift

### 2.2 설치 프로세스
1. GitHub 저장소 클론 및 프로젝트 빌드
2. 빌드된 앱을 Applications 폴더에 설치
3. 필요 시 코드 서명 및 공증 처리

### 2.3 도입 타당성 분석

**적합한 사용 케이스**
- 자주 사용하는 웹 서비스(Gmail, Notion, Slack) 앱화
- 사내 웹 대시보드 및 관리 시스템
- 생산성 향상 및 리소스 최적화 목적

**부적합한 케이스**
- 복잡한 브라우저 확장 기능 필요 시
- 크로스 플랫폼 지원 필요 시
- 고도의 커스터마이징이 필요한 경우

## 3. 실행 전략

### 3.1 우선순위별 앱 전환 계획

**Phase 1 — 핵심 업무 도구 (1주차)**
- Notion/Obsidian (지식 관리)
- Gmail/Outlook (이메일)
- Slack/Discord (커뮤니케이션)

**Phase 2 — 생산성 도구 (2주차)**
- Figma/Miro (디자인/협업)
- GitHub (코드 관리)
- Jira/Linear (프로젝트 관리)

**Phase 3 — 보조 도구 (3주차)**
- ChatGPT/Claude (AI 도구)
- Google Analytics (분석)
- 사내 대시보드

### 3.2 워크플로우 통합
- Dock 정리로 브라우저 탭 혼잡도 해소
- 단축키 설정으로 빠른 앱 전환 (Cmd+Tab)
- 알림 권한 관리로 업무 집중도 향상
